## Project Summary
BuildTrack is a monorepo application structured around three core pillars:
1. **Frontend (Web)**: Built with Next.js, serving project managers and finance teams with complex reporting and project overviews.
2. **Backend (API)**: Built with NestJS, acting as the secure gateway for data manipulation via PostgreSQL, Prisma, and Redis.
3. **Mobile App**: Built with Expo/React Native, serving on-field workers and subcontractors for quick logging and task management.
